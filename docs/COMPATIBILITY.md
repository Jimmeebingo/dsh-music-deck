# 1.0.1 兼容性验证

验证日期：2026-11-13。DSH 宿主版本：0.2.2-rc.1。以下是已测范围，不代表所有播放器与所有电脑的保证。

## 已验证

- 52 项回归检查通过：来源选择 16 项、系统音乐类型 5 项、操作能力 5 项、宿主请求及实例隔离 9 项、Windows / COM / 生命周期回归 17 项。
- Windows PowerShell 5.1 的 32 位、64 位进程均可编译音量与封面辅助代码；COM HRESULT 签名检查通过。
- 本机 Windows 11 的网易云音乐与 QQ 音乐均能提供系统媒体会话，实际读取到媒体类型、曲目信息、封面与每应用音量。测试未修改实际播放状态或音量。
- `npm pack` 生成的 13 文件包在带中文、空格的干净目录中直接启动实际 PowerShell 代理；封面、音量、状态与心跳均可用，测试进程退出后临时数据清理成功。
- 与 DSH 桌面 IPC 转发方式核对：转发后的 JSON 命令可不带 Origin；网页跨站请求与简单文本 POST 被拒绝。
- 多个活动音频输出设备、指定来源消失、读取超时、短暂状态写入失败及插件实例交叠均有回归用例。

## 使用条件与未覆盖范围

- 要求 Windows 10 1809 / build 17763 及以上，或 Windows 11，以及系统 Windows PowerShell 5.1。
- DSH 宿主和播放器必须在同一台电脑及同一 Windows 登录会话。远程 Web 浏览器不会把自己电脑的媒体会话传给宿主。
- 只能列出向 Windows 发布 SMTC 的会话。不同客户端版本、客户端设置、系统策略或权限限制可能使会话缺失；没有会话时需要先解决客户端的 SMTC 支持。
- 客户端提供哪些控制能力，插件才能使用哪些能力。本次网易云、QQ 音乐会话均未提供系统跳转能力，因此进度条不会发送跳转命令。
- 无法安全映射到音频进程的媒体 ID 可能只能显示信息与使用媒体控制，无法提供每应用音量；不会猜测进程并调整其他软件。
- 未在反馈者电脑、Windows 10 实机、32 位操作系统、ARM64 实机或所有音乐软件上逐一实测。32 位进程编译通过不等于所有 32 位系统已验证。
- 封面辅助读取有超时与失败回退；慢速客户端仍可能延迟一个状态刷新周期。测试不涵盖长期运行中的所有客户端或驱动异常。

## 反馈识别问题

先播放一首音乐，再打开卡片设置，使用“复制诊断信息”。反馈时附上 Windows build、DSH 版本、播放器版本和该诊断内容。诊断中的媒体来源 ID 是否出现，可区分“系统没有会话”和“插件选错来源”。请在公开贴出前检查内容是否包含你不希望公开的信息。

开发者可以在 Windows 仓库目录执行 `npm.cmd test` 重跑回归检查；测试不向真实播放器发送控制命令。
